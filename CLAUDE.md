# Project rules

- Never run `git commit` or `git push`. The user commits manually in GitHub Desktop.
- Never add `Co-Authored-By` lines or any AI-related notes in code, commits, or README.
- API keys live only in `.env` (listed in `.gitignore`). Never write keys into code and never display the contents of `.env`.
- Do not modify files in `data/`, except `data/arena.duckdb`, which is generated by `scripts/build_db.py`.
- Code, comments, and README in English. Talk to the user in Polish.
- Run `pytest` after every change.
